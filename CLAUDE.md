# NeRN — пам'ять для агента

Головний документ — `SPEC.md`. Працюй за розділом «Протокол роботи для Claude Code»: спершу план, код після «так»; нові залежності — лише з дозволу; жодних мережевих запитів у коді.

## Команди

| Команда                           | Що робить                                                            |
| --------------------------------- | -------------------------------------------------------------------- |
| `npm run dev`                     | Дев-сервер (http://localhost:5173)                                   |
| `npm run build`                   | Перевірка типів + продакшн-збірка в `dist/`                          |
| `npm run preview`                 | Роздає `dist/` з тим самим CSP, що й Netlify (http://localhost:4173) |
| `npm test`                        | Юніт-тести (Vitest), файли `src/**/*.test.ts`                        |
| `npm run e2e`                     | E2E (Playwright, Pixel 7 + iPhone 15). Спершу `npm run build`        |
| `npm run lint` / `npm run format` | ESLint / Prettier                                                    |
| `npm run icons`                   | Перегенерувати тимчасові іконки в `public/icons/`                    |

## Структура

- `src/engine/` — рушій PVT, чистий TS без React (Етап 1).
- `src/stats/` — формули, чисті функції + тести (Етапи 1–3).
- `src/db/` — Dexie: `schema.ts` (типи зі SPEC), `db.ts` (версії схеми).
- `src/i18n/` — `uk.ts` (джерело форми), `en.ts` (типізований як `Messages`), `format.ts` (множини, мова браузера).
- `src/ui/` — токени (`tokens.css`), шрифти (`fonts.css`), компоненти.
- `src/app/` — роутер, макети, тема, налаштування інтерфейсу.
- `src/features/<екран>/` — екрани.
- `netlify.toml` — CSP і заголовки. `vite.config.ts` читає CSP звідти для `preview`.

## Конвенції

- Кольори, шрифти, розміри — лише токени. Стандартні палітри Tailwind вимкнені (`--color-*: initial`).
- Шкала тексту: `text-12/14/16/20/28/40/72`. Радіуси: `rounded-card` (20), `rounded-button` (14), `rounded-inner` (10).
- Тексти — лише через `useI18n().m`. Без «!», крім ключів `newPeak`.
- Числа, що змінюються або стоять у стовпчик, — клас `tabular-nums` (не глобально).
- Коміти англійською, Conventional Commits. Один етап — одна гілка `stage-N-…`.
